01 / The standard

A process for the whole session—not another setup to chase.

Echelon defines the decisions around the trade so the trade itself is no longer improvised.

  1. A

    Before the window

    Prepare

    Start with the session conditions, key areas, and risk already defined. No rebuilding the plan once price begins moving.

  2. B

    Until qualified

    Wait

    Know which windows matter and what has to be present. If the condition is missing, standing aside is the correct position.

  3. C

    At the trigger

    Execute

    Use named setups, a defined invalidation, and size taken from the stop—not from how confident the trade feels.

  4. D

    When the rule says

    Stop

    Close the decision loop with daily limits, stand-down rules, and an honest review against the written standard.

No. You should understand futures mechanics, know what an NQ tick costs, and have some screen time. Echelon teaches a trading process, not the vocabulary of futures.

No. Echelon is not signals and nobody calls trades for you. You receive a defined process and execute it yourself. The room supports the work; it does not replace it.
